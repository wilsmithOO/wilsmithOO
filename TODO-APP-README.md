# To-Do List Application

A fully functional to-do list application with local storage functionality built with vanilla HTML, CSS, and JavaScript.

## Features

✨ **Core Functionality**
- ✅ Add, complete, and delete tasks
- 💾 Local storage persistence (tasks saved automatically)
- 🎯 Filter tasks by status (All, Active, Completed)
- 📊 Real-time statistics (Total, Completed, Remaining tasks)
- 🧹 Clear completed tasks or all tasks at once
- ⌨️ Enter key support for adding tasks

🎨 **User Experience**
- Responsive design (works on desktop and mobile)
- Smooth animations and transitions
- Beautiful gradient design
- Empty state message
- Task creation timestamp
- Intuitive interface with visual feedback

💡 **Technical Features**
- No dependencies required (vanilla JavaScript)
- Object-oriented design using ES6 classes
- Local Storage API for data persistence
- HTML escaping for security
- Keyboard navigation support

## How to Use

1. **Open the application**: Open `todo.html` in your web browser
2. **Add a task**: Type in the input field and click "Add Task" or press Enter
3. **Complete a task**: Check the checkbox next to the task
4. **Delete a task**: Click the "Delete" button on any task
5. **Filter tasks**: Use the filter buttons to view All, Active, or Completed tasks
6. **View statistics**: Check the stats section to see your progress
7. **Clear tasks**: Use "Clear Completed Tasks" or "Clear All Tasks" buttons

## Data Persistence

All your tasks are automatically saved to your browser's local storage. This means:
- ✅ Tasks persist after closing the browser
- ✅ Tasks are saved locally on your device
- ✅ No account or server required
- ⚠️ Tasks are specific to this browser/device
- ⚠️ Clearing browser data will delete tasks
